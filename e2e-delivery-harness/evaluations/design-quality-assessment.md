# 设计质量评估 (Design Quality Assessment)

## Purpose

本评估用于衡量技术设计文档的完整性与质量，覆盖设计完备性、一致性、可行性和合规性四个评分维度。采用加权评分法输出设计质量等级。

## Scoring Rubric

每项使用 0-4 分制评分：

| 分值 | 含义 | 说明 |
|------|------|------|
| 4 | Exemplary | 超出预期，可作为模板 |
| 3 | Good | 满足要求，少量可忽略不足 |
| 2 | Adequate | 基本满足，有明显改进空间 |
| 1 | Poor | 严重不足，需大幅调整 |
| 0 | Missing | 未涉及或未提供 |

## 使用时机

- 技术设计文档（HLD/LLD）编写完成后评审
- 跨团队设计评审前的自评
- 设计文档模板改进的基线参考

---

## 1. 设计完备性 (Completeness) — 权重 30%

- [ ] **DC-001** [4/3/2/1/0]: 设计文档包含完整的背景、目标、范围说明，非技术人员可理解设计动机
- [ ] **DC-002** [4/3/2/1/0]: 功能设计覆盖 REQ-* 中所有需求（覆盖率 ≥ 95%），有双向追溯表
- [ ] **DC-003** [4/3/2/1/0]: 非功能设计覆盖所有 NFR 项（性能/可用性/安全/可维护性），每项有具体方案
- [ ] **DC-004** [4/3/2/1/0]: 接口设计完整：请求/响应格式、状态码、错误格式、限流说明、版本策略
- [ ] **DC-005** [4/3/2/1/0]: 数据模型设计包含 ER 图、字段定义（类型/长度/约束/默认值）、索引策略
- [ ] **DC-006** [4/3/2/1/0]: 异常场景与边界条件已在设计中考虑（超时、并发、数据不一致、第三方故障）

## 2. 设计一致性 (Consistency) — 权重 25%

- [ ] **DS-001** [4/3/2/1/0]: 术语使用一致（同一概念在不同章节使用相同名称，无歧义）
- [ ] **DS-002** [4/3/2/1/0]: 设计风格与现有系统一致（遵循相同的模式/惯例/技术选型趋势）
- [ ] **DS-003** [4/3/2/1/0]: 文档内部无矛盾（前端描述与后端描述不对应、数据流图与接口定义不匹配等）
- [ ] **DS-004** [4/3/2/1/0]: 与关联设计文档引用一致（依赖服务的设计方案版本已对齐）

## 3. 设计可行性 (Feasibility) — 权重 25%

- [ ] **DF-001** [4/3/2/1/0]: 技术方案已有原型或 POC 验证（高风险/新引入技术栈），非纯理论方案
- [ ] **DF-002** [4/3/2/1/0]: 设计考虑了现有系统的约束（存量数据迁移、已有 API 兼容、部署环境限制）
- [ ] **DF-003** [4/3/2/1/0]: 实施成本可接受（开发人天在计划范围内，无隐藏成本）
- [ ] **DF-004** [4/3/2/1/0]: 关键风险已识别并定义了缓解措施，风险登记表完整

## 4. 设计合规性 (Compliance) — 权重 20%

- [ ] **DCP-001** [4/3/2/1/0]: 设计遵循团队/组织的设计规范（设计模板使用正确、图表标准统一）
- [ ] **DCP-002** [4/3/2/1/0]: 数据隐私与合规要求已考虑（GDPR/个人信息保护法/行业监管要求）
- [ ] **DCP-003** [4/3/2/1/0]: 可观测性设计已包含：日志（关键操作记录）、指标（业务和系统指标）、链路追踪
- [ ] **DCP-004** [4/3/2/1/0]: 国际化/本地化、可访问性（Accessibility）等横向关注点已考虑（如适用）

## Scoring Calculation

| 维度 | 权重 | 得分（/24） | 加权得分 |
|------|------|-------------|----------|
| 完备性 | 30% | __ / 24 | __ × 30% = __ |
| 一致性 | 25% | __ / 16 | __ × 25% = __ |
| 可行性 | 25% | __ / 16 | __ × 25% = __ |
| 合规性 | 20% | __ / 16 | __ × 20% = __ |
| **总分** | **100%** | | **__ / 4.0** |

### 质量等级判定

| 加权总分 | 等级 | 说明 |
|----------|------|------|
| 3.5 - 4.0 | A (优秀) | 设计质量优秀，可直接进入实施 |
| 2.8 - 3.4 | B (良好) | 设计质量良好，修复低分项后实施 |
| 2.0 - 2.7 | C (合格) | 设计基本可行，需补充完善后评审 |
| < 2.0 | D (不合格) | 设计不达标，需重新设计 |
