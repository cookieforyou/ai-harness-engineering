# Common Error Patterns Reference (常见错误模式参考)

## 概述

本文档汇总了 E2E 交付流程中常见的 AI 执行错误模式及其预防/处理方法，帮助 AI Agent 避免常见陷阱，提高输出质量。

## 通用错误模式

### 1. 跳步推理 (Step Skipping)

**问题描述**：AI 在推理过程中跳过关键步骤，直接给出结论。

**识别特征**
- 输出缺少中间推导过程
- 结论与输入之间缺乏逻辑链
- 关键假设未明确标注

**预防措施**
- 强制使用 Chain of Thought 模板
- 每个思维步骤必须显式输出
- 检查点验证中间结果

**修复方法**
```
IF 发现跳步
THEN
  1. 回溯到跳步点
  2. 补充中间推理步骤
  3. 重新验证推导逻辑
  4. 更新输出
END
```

### 2. 幻觉生成 (Hallucination)

**问题描述**：AI 生成看似合理但实际不准确的信息。

**识别特征**
- 引用不存在的文档/数据
- 技术细节与事实不符
- 无法提供信息来源

**预防措施**
- 要求标注信息来源
- 验证外部引用的存在性
- 关键数据要求可追溯

**修复方法**
```
IF 发现幻觉风险
THEN
  1. 标注 [需验证]
  2. 提供验证方法
  3. 要求用户确认
  4. 使用更保守的表述
END
```

### 3. 过度简化 (Over-simplification)

**问题描述**：AI 忽略重要细节或边界情况。

**识别特征**
- 缺少异常处理描述
- 边界条件未考虑
- 简化假设未说明

**预防措施**
- 要求列出边界条件
- 检查清单覆盖边界情况
- 输出模板包含异常场景

### 4. 不一致输出 (Inconsistency)

**问题描述**：输出内容前后矛盾或与前置阶段不一致。

**识别特征**
- 术语定义前后不一致
- 数据值在不同章节矛盾
- 与输入需求不匹配

**预防措施**
- 建立术语表保持一致
- 交叉验证数据一致性
- 可追溯性检查

**修复方法**
```
IF 发现不一致
THEN
  1. 识别所有不一致点
  2. 确定正确版本
  3. 更新所有相关位置
  4. 添加一致性检查
END
```

### 5. 模糊表达 (Ambiguity)

**问题描述**：输出表达不够清晰，存在多种理解方式。

**识别特征**
- 使用"可能"、"大概"等模糊词
- 缺少具体数值
- 操作步骤不明确

**预防措施**
- 要求具体化表述
- 使用 SMART 标准
- 验收标准必须可测试

## 分阶段常见错误

### 需求分析阶段

| 错误模式 | 描述 | 预防 | 处理 |
|----------|------|------|------|
| 需求遗漏 | 关键需求未识别 | 业务流程逐环节检查 | 补充遗漏需求 |
| 优先级错排 | 优先级与价值不匹配 | 干系人确认优先级 | 重新评估排序 |
| 假设未标注 | 隐含假设未说明 | 要求显式列出假设 | 补充假设说明 |
| 验收标准模糊 | 无法验证的标准 | SMART 原则检查 | 重新定义标准 |

### 系统设计阶段

| 错误模式 | 描述 | 预防 | 处理 |
|----------|------|------|------|
| 过度设计 | 设计超出需求范围 | 与需求对照检查 | 简化设计 |
| 架构耦合 | 模块间高耦合 | 依赖分析检查 | 重构模块边界 |
| 扩展性缺失 | 未考虑未来变化 | 需求变化点分析 | 增加扩展点 |
| 性能目标不明 | 缺少性能指标 | 明确非功能需求 | 补充性能指标 |

### 任务分解阶段

| 错误模式 | 描述 | 预防 | 处理 |
|----------|------|------|------|
| 粒度不均 | 任务大小差异大 | 1-3天标准检查 | 拆分/合并任务 |
| 循环依赖 | 任务间循环依赖 | 依赖图分析 | 引入抽象层 |
| 估算偏差 | 估算与实际差距大 | 历史数据参考 | 增加风险缓冲 |
| 遗漏任务 | 关键任务未识别 | 完整性检查清单 | 补充遗漏任务 |

### 开发实现阶段

| 错误模式 | 描述 | 预防 | 处理 |
|----------|------|------|------|
| 规范违反 | 代码不符合规范 | Linting 检查 | 重构代码 |
| 测试不足 | 单元测试覆盖不足 | 覆盖率检查 | 补充测试用例 |
| 安全漏洞 | 引入安全风险 | SAST 检查 | 修复漏洞 |
| 文档缺失 | 代码注释不充分 | 代码审查 | 补充注释 |

### 测试验证阶段

| 错误模式 | 描述 | 预防 | 处理 |
|----------|------|------|------|
| 用例遗漏 | 关键场景未覆盖 | 测试矩阵检查 | 补充用例 |
| 断言不足 | 验证点不充分 | 断言清单检查 | 增加断言 |
| 环境差异 | 测试与生产环境不同 | 环境一致性检查 | 同步环境配置 |
| 回归遗漏 | 变更影响未覆盖 | 变更影响分析 | 补充回归用例 |

### 部署发布阶段

| 错误模式 | 描述 | 预防 | 处理 |
|----------|------|------|------|
| 验证不充分 | 部署后验证不足 | 验证清单检查 | 补充验证步骤 |
| 回滚方案缺失 | 无有效回滚方案 | 回滚测试 | 制定回滚方案 |
| 通知遗漏 | 相关方未及时通知 | 通知清单检查 | 发送通知 |
| 监控配置缺失 | 部署后监控不足 | 监控覆盖检查 | 配置监控 |

### 监控运维阶段

| 错误模式 | 描述 | 预防 | 处理 |
|----------|------|------|------|
| 告警风暴 | 告警数量过多 | 告警聚合检查 | 调整告警阈值 |
| 阈值不当 | 告警阈值设置不合理 | 趋势分析检查 | 调整阈值 |
| SLO 违反 | SLO 目标未达成 | SLO 趋势监控 | 启动应急响应 |
| 知识丢失 | 运维经验未沉淀 | 知识库检查 | 更新文档 |

## 错误处理流程

```
┌─────────────────────────────────────────────────────────┐
│  错误检测                                                │
│  ├── 自动检测 (规则/模板检查)                           │
│  ├── 交叉验证 (与其他资产比对)                          │
│  └── 人工反馈 (用户指出)                                │
└────────────────────────┬────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│  错误分类                                                │
│  ├── Critical (阻塞性)                                  │
│  ├── High (影响较大)                                    │
│  ├── Medium (有影响)                                    │
│  └── Low (轻微)                                         │
└────────────────────────┬────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│  处理决策                                                │
│  ├── 自动修复 (规则明确)                                │
│  ├── 提示修正 (需用户确认)                              │
│  └── 升级处理 (超出能力范围)                            │
└────────────────────────┬────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│  修复执行                                                │
│  ├── 定位问题点                                         │
│  ├── 执行修正                                           │
│  └── 验证修复                                           │
└────────────────────────┬────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│  记录归档                                                │
│  ├── 更新资产                                             │
│  └── 记录经验                                             │
└─────────────────────────────────────────────────────────┘
```

## 错误预防检查清单

### 执行前

- [ ] 确认变量已填充
- [ ] 确认前置阶段已完成
- [ ] 确认输入信息完整
- [ ] 确认理解任务目标

### 执行中

- [ ] 每个步骤有输出
- [ ] 中间结果已验证
- [ ] 假设条件已标注
- [ ] 遇到异常已处理

### 执行后

- [ ] 完整性检查通过
- [ ] 一致性检查通过
- [ ] 可追溯性检查通过
- [ ] 质量标准达标
