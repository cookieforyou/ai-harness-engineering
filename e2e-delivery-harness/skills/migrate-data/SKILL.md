# Skill: 数据迁移 (Data Migration)

## 概述

本 Skill 定义了数据迁移领域的核心知识和最佳实践。

## 核心知识

### 迁移策略
- BIG_BANG: 一次性迁移
- PARALLEL: 双写并行
- PHASE: 分阶段迁移

### 数据校验
- 记录数校验
- 字段和校验
- 抽样校验
- 全量校验
