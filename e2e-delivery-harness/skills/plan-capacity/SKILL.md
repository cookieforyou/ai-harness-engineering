# Skill: 容量规划 (Capacity Planning)

## 概述

本 Skill 定义了容量规划的核心知识和方法。

## 核心知识

### 容量指标
- CPU 利用率
- 内存利用率
- 存储利用率
- TPS/QPS
- 响应时间

### 扩容策略
- 垂直扩展
- 水平扩展
- 混合扩展
