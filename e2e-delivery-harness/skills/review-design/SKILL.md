# Skill: 技术方案评审 (Technical Design Review)

## 概述

本 Skill 定义了技术方案评审的核心知识和评审方法。

## 评审方法

### 评审维度
- 需求匹配
- 技术可行性
- 安全性
- 性能
- 可维护性
- 成本

### 评审 Checklist
- [ ] 需求完整性
- [ ] 技术选型合理性
- [ ] 风险识别
- [ ] 扩展性考虑
- [ ] 安全合规
