# Deployment Skill

## Use When

使用此技能的场景：

- 测试通过后，需要进行部署发布
- 需要规划部署策略和回滚方案
- 需要配置 CI/CD 流水线
- 需要进行环境迁移或升级

## Expected Input

### 必需输入

| 输入项 | 类型 | 描述 |
|--------|------|------|
| 测试通过报告 | 文件 | 测试阶段的验收通过文件 |
| 部署包 | 文件 | 待部署的应用包 |
| 部署目标 | 文本 | 目标环境配置 |

### 可选输入

| 输入项 | 类型 | 描述 |
|--------|------|------|
| 回滚方案 | 文件 | 回滚计划和方案 |
| 配置变更 | 文件 | 本次部署的配置变更 |

## Instructions

### 步骤 1：部署规划

**目标**：制定详细的部署策略和计划

**操作**：
1. 确定部署策略（蓝绿/滚动/灰度）
2. 确定部署时间窗口
3. 规划部署步骤
4. 分配部署角色
5. 制定回滚方案

**检查点**：
- [ ] 策略已确定
- [ ] 时间已安排
- [ ] 回滚方案已准备

### 步骤 2：环境准备

**目标**：准备目标部署环境

**操作**：
1. 验证环境可用性
2. 检查资源状态
3. 确认网络连通
4. 准备环境配置
5. 执行数据备份

**检查点**：
- [ ] 环境可用
- [ ] 资源充足
- [ ] 备份完成

### 步骤 3：部署前检查

**目标**：确保部署条件满足

**操作**：
1. 确认人员就位
2. 确认通知到位
3. 确认回滚准备
4. 确认监控就绪
5. 确认沟通渠道

**检查点**：
- [ ] 人员已就位
- [ ] 通知已发送
- [ ] 回滚就绪

### 步骤 4：部署执行

**目标**：按计划执行部署

**操作**：
1. 执行预检查
2. 按步骤执行部署
3. 记录执行日志
4. 监控部署状态
5. 及时报告异常

**检查点**：
- [ ] 按计划执行
- [ ] 日志已记录
- [ ] 异常已处理

### 步骤 5：验证检查

**目标**：验证部署结果

**操作**：
1. 执行功能验证
2. 执行健康检查
3. 执行数据验证
4. 记录验证结果
5. 确认部署成功

**检查点**：
- [ ] 功能验证通过
- [ ] 健康检查通过
- [ ] 数据验证通过

### 步骤 6：监控跟踪

**目标**：持续监控部署后状态

**操作**：
1. 监控核心指标
2. 关注异常告警
3. 定期报告状态
4. 处理异常情况
5. 确认稳定后完成

**检查点**：
- [ ] 监控已配置
- [ ] 状态稳定
- [ ] 无新增告警

### 步骤 7：文档归档

**目标**：完成部署文档归档

**操作**：
1. 整理部署文档
2. 记录变更清单
3. 更新配置文档
4. 归档部署记录
5. 总结经验教训

**检查点**：
- [ ] 文档已整理
- [ ] 记录已归档
- [ ] 经验已总结

## Expected Output

### 产出列表

1. **部署计划**：详细的部署步骤和时间表
2. **回滚方案**：回滚操作步骤和条件
3. **部署检查清单**：部署后的验证检查项
4. **部署报告**：部署执行记录和结果

### 输出格式

```markdown
## 部署报告

### 部署信息
...

### 部署计划
...

### 回滚方案
...

### 部署执行
...

### 验证结果
...

### 监控状态
...

### 结论
...
```

## Quality Criteria

| 维度 | 标准 | 检查方法 |
|------|------|----------|
| 部署安全 | 过程安全可控 | 执行记录检查 |
| 回滚能力 | 可快速回滚 | 回滚方案检查 |
| 验证完整 | 验证覆盖全面 | 检查清单检查 |
| 文档完整 | 文档归档完整 | 归档检查 |
