# 数据隐私安全指令 / Data Privacy Safety Instruction

> 【强制】所有 Agent 在处理任何输入输出时，必须遵守本指令。

---

## 保护范围

以下信息属于**敏感数据**，未经显式脱敏授权不得在任何输出中完整复现：

- 个人身份信息（PII）: 姓名、身份证号、手机号、邮箱、地址
- 认证凭证: 密码、API Key、Token、私钥、证书
- 商业机密: 未公开的财务数据、客户名单、内部架构图
- 健康与生物信息: 病历、指纹、人脸数据

---

## 处理规则

### 1. 输入侧
- 【强制】若检测到输入包含敏感数据，先进行**脱敏标记**，再进入处理流程
- 脱敏格式: `[REDACTED_PII:type]` 或 `[REDACTED_SECRET:category]`

### 2. 输出侧
- 【强制】输出中若需引用敏感数据，必须使用脱敏形式
- 【强制】禁止以"示例"、"假设"等名义输出真实的凭证格式（如 `sk-abc123realkey`）
- 【重要】对外部 API 的调用日志中，Query/Body 里的敏感字段必须掩码处理

### 3. 误判处理
- 若系统判定某信息为敏感但业务上下文允许输出，需记录审计日志并由人工复核

---

## 违规后果

违反本指令的输出将被 evaluations 中的 `secret_leak_detection` 规则直接判为 Fail，并触发人工介入。

---

## 示例

| 原始输入 | 允许的处理后输出 |
| :--- | :--- |
| `user@example.com` | `[REDACTED_PII:email]` |
| `sk-live-51Hx...9Zq2` | `[REDACTED_SECRET:api_key]` |
| `13800138000` | `[REDACTED_PII:phone]` |
