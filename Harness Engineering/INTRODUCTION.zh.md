# AI Harness 资产库介绍

## 什么是 AI Harness 资产库

本资产库是 **Harness Engineering（驾驭工程）** 方法论在工程实践中的落地载体。它将 AI 交付过程中所需的全部控制要素——Agent、指令、提示词、评估、场景、技能——进行结构化沉淀，形成一套可编排、可复用、可演进的资产体系。

> **核心理念**: "Humans steer, Assets enable, Agents execute."  
> 人类掌舵方向，资产提供能力，智能体负责执行。

---

## 为什么需要统一资产库

在 AI 工程化交付中，团队常面临以下痛点：

- **提示词散落**: 各项目重复造轮子，提示词质量参差不齐
- **Agent 行为不可预期**: 缺乏统一的角色定义与约束机制
- **评估缺失**: 无法量化 AI 输出质量，难以持续改进
- **场景碎片化**: E2E 流程断裂，人工介入点混乱
- **知识流失**: 核心工程经验随人员变动而流失

本资产库通过 **八大模块** 的系统化设计，一次性解决上述问题。

---

## 八大模块概览

| 模块 | 职责 | 典型交付物 |
| :--- | :--- | :--- |
| **agents** | 定义 AI Agent 的角色、目标、能力边界与工具集 | 角色卡 (Role Card)、Agent 配置文件 |
| **evaluations** | 建立质量评估体系，覆盖正确性、安全性、可用性 | 评测集、评分标准、自动化测试脚本 |
| **instructions** | 编写系统级指令与行为约束，确保 Agent 行为可控 | 系统提示、安全护栏、输出格式约束 |
| **prompts** | 沉淀高质量、场景化的提示词模板 | 分类提示词库、变量化模板 |
| **scenarios** | 编排端到端工作流，定义输入输出、步骤、人机协作点 | 场景说明书、流程图、编排 YAML |
| **skills** | 封装可复用的原子能力，供 Agent 或场景调用 | 技能定义文件、工具函数描述、Schema |
| **standards** | 制定资产规范、命名约定、版本策略与最佳实践 | 规范文档、检查清单 (Checklist) |
| **templates** | 提供项目脚手架与快速启动模板 | 项目模板、初始化脚本、示例代码 |

---

## 与六层架构的映射

本资产库的设计直接映射 Harness Engineering 的六层技术架构：

```
目标层 (Goal)        →  scenarios/  +  agents/ 定义目标与成功标准
策略层 (Strategy)    →  skills/  +  prompts/ 提供规划与推理能力
工具层 (Tooling)     →  skills/ 中集成外部工具接口
约束层 (Constraint)  →  instructions/  +  standards/ 实施边界控制
反馈层 (Feedback)    →  evaluations/ 完成质量闭环
监控层 (Observability)→ standards/ 中定义日志、追踪与审计规范
```

## 适用场景

- **全自动软件交付**: 从需求文档生成到代码实现、测试、部署
- **智能文档工程**: 技术文档自动撰写、审校、多语言翻译
- **数据管道自动化**: ETL 流程设计、数据质量校验、异常处理
- **产品原型迭代**: 根据 PRD 快速生成可运行的 MVP 及评审反馈
- **科研与知识生产**: 文献综述、实验报告、论文辅助写作
